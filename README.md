# 🎯 ClaimTrace — Source-Grounded Factuality & Hallucination Auditor

> Part of the **Antigravity 20-Project Systems Engineering Portfolio**

ClaimTrace is a strict evidence-verification engine that detects hallucinations, polarity inversions, and unsupported claims in text generated by large language models or unverified drafts.

---

## 🏗️ Architecture

```
Candidate Text (AI Response / Draft)
         │
         ▼
┌───────────────────────────┐
│      ClaimExtractor       │ ──> Sentence & Proposition Decomposition
└───────────────────────────┘
         │
         ▼
┌───────────────────────────┐
│      EvidenceMatcher      │ ──> Token Containment + Polarity Inversion + Numeric Check
└───────────────────────────┘
         │
         ▼
┌───────────────────────────┐
│  Strict 4-State Decision  │ ──> SUPPORTED | CONTRADICTED | INSUFFICIENT | UNVERIFIED
└───────────────────────────┘
         │
         ▼
Interactive Factuality Studio (ui/index.html)
```

---

## 🚀 Quick Start

### 1. Run Tests

```bash
npm test
```

### 2. Launch Individual UI Dashboard

